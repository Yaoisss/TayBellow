# README 中文翻译

状态：设计已确认（2026-10-10），待转实施计划。

## 背景

仓库根目录 `README.md` 目前是英文（214 行，上游 qwen-code 的门面结构：徽章、
Why、安装、Quick Start、接口对照表、能力对比、SWE-bench 评测、生态、隐私、贡献、
致谢）。本仓库为个人自用分支，实际使用者是中文母语的本人，需要一份中文版便于阅读
与检索。

## 目标

把 `README.md` 的现有内容**逐段翻译成中文**：章节划分、顺序、表格、徽章、图片、
链接与数据全部保持原样，只把正文语言换成中文。

## 非目标

- 不重排、不增删章节（评测、生态、能力对比表、隐私、致谢全部保留）。
- 不新增目录、目录锚点或部署手册类章节。
- 不做中英双语版本，不新增文件。
- 不改任何链接目标、图片地址、徽章地址、命令、路径与表格数值。
- 不引入本机部署信息（README 保持通用，不外泄真实地址）。

## 翻译口径

| 类别                                                                         | 处理                                                              |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 正文、标题、表头、图片 alt、details 摘要                                     | 译成中文                                                          |
| 命令、路径、URL、代码块内容、环境变量、标识符                                | 原样保留                                                          |
| 产品与协议名（Tay Bellow、Claude Code、npm、Docker、MCP、SDK、ACP、PWA 等）  | 原样保留                                                          |
| 沿用已久的术语（token、headless、standalone、Agent Teams、Plan Mode、Hooks） | 保留英文，必要时中文加括号注解                                    |
| 表格数值、评级符号（✓ / —）                                                  | 不变                                                              |
| 徽章区块与多语言链接行                                                       | 徽章原样；多语言链接行的文字本身是各语言名，原样保留              |
| Markdown 链接文字                                                            | 译成中文，**链接目标不变**                                        |
| 内部锚点                                                                     | 标题中文化后同步更新（原文唯一锚点 `#quick-start` → `#快速开始`） |

## 验收标准

1. 章节标题与原文一一对应（数量与顺序一致，`^#` 行数同为 13）。
2. 代码块数量一致（`^` + 三个反引号 的行数同为 16），块内内容不变。
3. 链接集合一致：抽取两版的 URL 集合，除内部锚点 `#quick-start` → `#快速开始` 外完全相同。
4. 表格行数与数值不变。
5. `npx prettier --check README.md` 通过。
6. 正文无英文段落；英文只出现在命令、路径、URL、代码块、产品名与保留术语中。

## 验证方案

- 结构对比：`git show HEAD:README.md` 与新版各自抽取 `^#` 标题行、`^` + 三个反引号 行、
  `https?://` URL 与 `^|` 表格行，逐项比对数量（URL 集合还需逐条 diff）。
- 术语一致性：按上表抽查全篇标题与表头。
- 格式：`npx prettier --check README.md`。
- 通读：确认无漏译段落、无生硬直译、无英文整句残留。

## 风险

- **术语直译生硬**：如 "Agentic"、"Harness" 一类无统一译法的词，保留英文或中英并置，
  以可读性优先（已在上表给出译名，实施时抽查一致性）。
- **表格与代码块内的英文**：属"保留英文"范畴，不做中文化，避免破坏可复制性。
- **英文原文只存于 git 历史**：翻译后若要回看原句，用
  `git show <翻译前提交>:README.md`。
